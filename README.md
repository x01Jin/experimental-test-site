## Core Capabilities

- **Infinite Scrolling Depth**: Continuous procedural generation of corrupted classified reports, bio-hazard specimens, and cursed interactive terminals.
- **Dynamic Visual Degradation**: Progressive decomposition spanning subtle pixel softening, severe pixelation, glitch slicing, fragmented image shards, Zalgo text decay, and abstract aggressive glitch patterns (moiré lattices, RAM dumps, hazard slashes).
- **Internet Specimen Corruption Pipeline**: Ingestion of photographic internet specimens with real-time canvas downsampling, RGB color splitting, inverted solarization chunks, and demonic biometric facial features.
- **Unexpected Quick Abstract Jumpscares**: Lightning-fast, non-blocking occurrences (sudden loud crash noises, shuddering critical error popups, severely distorted internet specimens, signal tears) spaced out with global cooldowns to catch users completely offguard without interrupting their scroll.
- **Pure Web Audio API Synthesis**: Zero external audio assets; real-time procedural sub-bass drones, authentic BSOD buffer stutter, pitch-stretched static bursts, and high-gain waveshaper hard-clipping distortion.
- **Localized Aggressive Shaking**: Isolates violent tremors strictly to cards, popups, and creepy visual artifacts while preserving smooth, unhindered page scrolling.
- **Procedural Canvas Nightmares**: Real-time canvas rendering of tracking bloodshot eye specimens, CRT scanline shimmers, and noise lattices.
- **Browser Autoplay Compliance**: Sensory calibration gatekeeper with photosensitivity warnings, volume limiter, and manual panic testing triggers.
