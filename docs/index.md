## Operational Overview

The application functions as a client-side real-time interactive simulation. The user scrolls downward through an endless succession of corrupted administrative and biological incident records. As virtual depth increases:
- Individual elements, cards, and creepy artifacts undergo aggressive localized spasms and tremors without shaking the entire document viewport.
- Interactive widgets (radio tuners, black-box audio players, redactions, CCTV cameras, heartbeat sensors) respond with synchronized synthesized audio feedback.
- Text content is dynamically corrupted with multi-tiered Zalgo combining marks.
- Audio synthesis accelerates in glitch frequency, volume, and multi-layered atmospheric horror events.
- High-intensity, non-blocking abstract jumpscares (loud crashes, twitching system error popups, distorted internet photos, signal tears) trigger unpredictably upon crossing depth milestones or rapid scrolling.
